# 📄 PRD: 2D 턴제 배틀 게임 (MVP)

## 1. 개요
- **게임 장르**: 2D 턴제 RPG (사이드 뷰)  
- **레퍼런스**:  
  - **시점**: 메이플스토리와 같은 사이드 뷰  
  - **전투**: 포켓몬스터 시리즈와 유사한 랜덤 인카운터 + 턴제 배틀  
- **목표**: MVP 단계에서 플레이어가 맵을 탐험하고, 풀숲에서 몬스터와 랜덤 배틀을 경험할 수 있도록 구현  
- **플랫폼**: PC (Unity Editor 실행)  
- **차후 확장**: 모바일 대응, 멀티플레이, 스프레드시트 연동  

---

## 2. 주요 기능 (MVP 범위)

### 2.1 탐험 (Exploration)
- **플레이어 이동**:  
  - 좌/우 이동, 점프 가능  
  - 간단한 2D 물리 기반 이동 (Rigidbody2D 사용)  
- **맵 구성**:  
  - 사이드 뷰 맵 (예: 평지 + 풀숲)  
- **랜덤 인카운터**:  
  - 풀숲에 들어갈 경우 일정 확률로 몬스터 출현  
  - 전투 화면으로 전환  

### 2.2 전투 (Battle System)
- **배틀 시작**:  
  - 화면이 전투 UI로 전환  
  - 몬스터와 플레이어(대표 캐릭터) 등장  
- **턴제 진행**:  
  - 플레이어 → 몬스터 순서대로 턴 진행  
  - 플레이어: 스킬 선택 → 실행  
  - 몬스터: AI 기반 무작위 스킬 선택  
- **승패 조건**:  
  - HP 0 → 패배 처리  
  - 플레이어 승리 시: 전투 종료 후 맵 복귀  
  - 플레이어 패배 시: Game Over 처리  

### 2.3 데이터 관리
- **데이터 구조**:  
  - **ScriptableObject**를 활용해 캐릭터, 몬스터, 기술 정의  
  - 추후 Google Spreadsheet 연동을 통해 자동 동기화 (MVP는 ScriptableObject로만 진행)  

- **데이터 예시**:  
  - **플레이어/몬스터 데이터**  
    - 이름, HP, 공격력, 방어력, 속도, 사용 가능한 스킬 목록  
  - **기술 데이터**  
    - 이름, 위력, 타입, 효과

## 3. 시스템 요구사항

### 3.1 플레이어 이동
- **컨트롤**:  
  - ← / → : 좌우 이동  
  - Space : 점프  
- **구현 방식**: Rigidbody2D + Collider2D  

### 3.2 랜덤 인카운터
- **풀숲 영역 (Trigger Collider)**  
- 진입 시 일정 확률(예: 20%)로 몬스터 배틀 발생  
- 인카운터 발생 시 → 전투 씬 전환  

### 3.3 전투 시스템
- **전투 씬**  
  - UI: HP 게이지, 스킬 선택 메뉴  
  - 플레이어, 몬스터 캐릭터 애니메이션 배치  
- **턴 진행 로직**  
  1. 플레이어 스킬 선택  
  2. 데미지 계산 → 몬스터 HP 감소  
  3. 몬스터 차례 → 랜덤 스킬 선택  
  4. 승패 여부 체크  
- **데미지 공식 (단순화 버전)**:  
'Damage = SkillPower + (Attacker.Attack - Defender.Defense)'
